# KIVANO storefront (version 1)

Static storefront for KIVANO, a digital PDF ebook store.

## What works
- Responsive homepage, shop, search, filters and sorting
- 8 demo product listings and product detail windows
- Shopping cart saved in the visitor's browser, demo discount code `KIVANO10`

## What does NOT work yet
- Payments: the Checkout button shows a notice only
- Secure PDF downloads, customer accounts, orders, admin area and database
- Newsletter signup (not connected to any service)

All products and reviews are demo content.

## Files
- `index.html` the whole storefront (HTML, CSS and JavaScript in one file)
- `404.html` page-not-found screen
- `robots.txt` search engine rules

## Deploy
Host as a static site (GitHub Pages, Cloudflare Pages or Netlify). No build step is needed.
